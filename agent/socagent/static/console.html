On the lab machine

The repo already registers the tiny-soc MCP server in .mcp.json. It runs over stdio and needs no token.

  1. Open a terminal in the repo and start Claude Code: 
    cd ~/githubcode/tiny-agenticsoc && claude
  2. Approve the project server tiny-soc when Claude Code asks. /mcp shows its 7 read-only tools.
  3. Ask in plain language, for example: "Use tiny-soc to rebuild the process tree for the rundll32 that touched lsass on win-victim."
